# Display typeface

The smart display serves Manrope locally. It makes no requests to a font CDN.

- Typeface: [Manrope](https://github.com/sharanda/manrope), variable weight 200–800.
- Source: [Google Fonts distribution](https://github.com/google/fonts/tree/main/ofl/manrope).
- File: `Manrope-Variable.ttf`, downloaded 2026-09-19.
- SHA-256: `3ae11c49db0455a3cc33e37d380f20fdb8c7f8b41dc07625c177e3d87a9d6ae6`.
- License: SIL Open Font License 1.1; the original notice is in [Manrope-OFL.txt](Manrope-OFL.txt).

The original font is unmodified; only its filename was simplified.
