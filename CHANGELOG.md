# Changelog

## 0.1.0-alpha.1

- First public source package for the Waveshare ESP32-S3-Touch-AMOLED-1.75.
- Round display UI, local speech, configurable Echo/Hermes agent, Home Assistant,
  Spotify Connect, explicit memory, routines and background research.
- Portable deployment and board configuration with private runtime state excluded.
- Setup/hardware documentation, source attribution and automated publication checks.
- Includes host 0.26.0 and firmware 0.13.0; physical acceptance gaps are documented.
